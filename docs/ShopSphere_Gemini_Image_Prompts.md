# ShopSphere: 38 Image Prompts for Gemini

## How to use

1. Open **one Gemini chat** and use it for all pages, so the style stays the same.
2. Copy ONE prompt at a time (each is complete by itself, the style is already included).
3. If a screen comes out wrong, ask Gemini: *"Keep exactly the same style and colours, but fix: ..."*.
4. Image generators sometimes misspell text. If words look wrong, say: *"Use fewer words and spell all text correctly."*
5. For the 3 Delivery pages the prompt asks for a mobile screen; all others are desktop.

---
